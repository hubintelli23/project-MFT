# MFT 인화순환록 — 전투 체험판

> 현재 버전: **v0.2** (index.html)

세계관 프로젝트 **MFT(인화순환록)** 설정집을 바탕으로 만든 **3D 액션 JRPG 전투 체험판(버티컬 슬라이스)**입니다.
주인공 연우의 붓/검 전환 전투와 청매 가주 **청류** 보스전을 브라우저에서 플레이할 수 있습니다.

- 장르: 3D 액션 JRPG (쿼터뷰 고정 카메라)
- 플랫폼: 웹 브라우저 (PC · 모바일, 모바일은 가로 화면 권장)
- 엔진: Three.js r128 (CDN 로드) · 파일 하나(`index.html`)로 동작
- 아트 방향: 수묵화 톤 — 탁기(검붉음)를 정화하면 비취색과 꽃잎이 번지는 연출

---

## 실행 방법

1. `index.html`을 브라우저로 열면 바로 실행됩니다. 별도 설치나 빌드가 필요 없습니다.
2. 인터넷 연결이 필요합니다. Three.js와 글꼴을 CDN에서 불러옵니다.
3. 웹에 올리려면 `index.html`을 GitHub Pages 같은 정적 호스팅에 업로드하면 됩니다.

## 조작법

### 키보드 · 마우스

| 입력 | 동작 |
|---|---|
| `W` `A` `S` `D` | 이동 |
| `C` / 마우스 좌클릭 | 공격 (연타 시 1~4타 콤보) |
| 마우스 좌클릭(또는 `C`) **꾹 누르기** | 강공격 |
| `Space` | 점프 |
| `Space` → 공중에서 좌클릭 | 점프 공격 |
| `Space` → 공중에서 좌클릭 꾹 누르기 | 점프 강공격 (내려찍기) |
| `Q` | 스킬 1 |
| `E` | 스킬 2 |
| `F` | 붓 ↔ 검 전환 |
| `R` | 궁극기 |
| `Shift` | 회피 |
| `Esc` / `P` | 일시정지 |
| `Space` / `Enter` / `C` / 클릭 | 대화 넘기기 |

> 강공격은 약 0.3초 이상 누르면 발동합니다. 누르는 동안 발밑 원이 커지면서 충전 상태를 보여줍니다.
> 회피 키는 요청된 키 배치에 없어서 `Shift`로 임시 지정했습니다.

## 핵심 전투 시스템

### 딜링 루프 — 만묵형상(萬墨形象)

```
붓 모드로 먹선 낙인 부여 (최대 5중첩)
   → 검 모드로 전환해 낙인을 베어 개화(폭발)
   → 방어막 · 체력 · 백묵화 게이지 · 전환 게이지 충전
```

### 붓 모드 (낙인 · 제어 · 방어)

| 구분 | 기술 | 효과 |
|---|---|---|
| 공격 1~4타 | 횡참 → 역횡참 → 원형 참격 → 광역 묵화 개화참 | 부채꼴 범위 낙인, 3타 끌어당김, 4타 360도 넉백 |
| 강공격 | 응묵결쇄 | 낙인 2중첩 + 속박 |
| 점프 공격 | 비묵호선 | 공중에서 낙인 부여 (점프 1회당 2번) |
| 점프 강공격 | 비취묵파 | 내려찍어 지면 먹물 파동 · 광역 낙인 + 방어막 |
| 스킬 1 (`Q`) | 만묵소진 | 소용돌이로 적을 끌어모음 + 방어막 |
| 스킬 2 (`E`) | 묵향결쇄 | 부채꼴 먹물 분사, 속박 + 낙인 · **인화 룬에 먹선 연결** |
| 패시브 | 비취묵령결 | 붓 모드일 때 방어막이 천천히 재생 |

### 검 모드 (딜링 · 정화)

| 구분 | 기술 | 효과 |
|---|---|---|
| 공격 1~4타 | 사선 참격 → 역참 → 종참 → 정화의 십자 참격 | 타격마다 낙인 개화, 4타는 남은 낙인 전부 개화 |
| 강공격 | 점묵폭화 | 낙인 전부 개화(1.5배) + 대량 방어막 |
| 점프 공격 | 비검무공 | 공중 2연속 베기, 적을 띄움 |
| 점프 강공격 | 백아강하참 | 내려찍기 강타, 낙인 개화 + 잡몹 다운 |
| 스킬 1 (`Q`) | 점묵개화 | 관통 찌르기, 낙인 즉시 개화 |
| 스킬 2 (`E`) | 유묵섬참 | 3연속 돌진 참격 · **연결된 룬 폭파** |
| 회피 반격 | 역린의 검무 : 녹각공명 | 적 공격이 닿기 직전 회피하면 반격 + 방어막 |

### 붓 ↔ 검 전환 (`F`)

| 방향 | 기본 전환 | 게이지 FULL 강화 전환 |
|---|---|---|
| 붓 → 검 | 추사 정화 (돌진 찌르기 + 개화) · 환묵잔영 분신을 남김 | 진명 정화 (화면 전체 개화 + 치명타 강화 + 체력 침식 일시 정지) |
| 검 → 붓 | 화묵이탈 (후방 점프 + 광역 낙인) · 비검 사출 | 막묵 결계 (주변 속박 + 낙인 5중첩 + 방어막 최대 + 붓 범위 확대) |

### 백묵화(白墨化)

개화할 때마다 게이지가 찹니다. 강해지는 만큼 위험도 커집니다.

| 단계 | 게이지 | 명칭 | 효과 |
|---|---|---|---|
| 1 | 25% | 용의 비늘 | 받는 피해 -10%, 경직 저항 |
| 2 | 50% | 용안 개안 | 치명타 +20% |
| 3 | 75% | 사지 야수화 | 이동·공격 속도 증가, 회피 시 잔상 공격 |
| 4 | 100% | 영로 화경 | 피해 +30%, 전신 순백화 · **12초 후 체력이 계속 깎임** |

궁극기 **『천지수묵 : 만화정계』**를 쓰면 백묵화가 0단계로 초기화되고, 10초간 탁기에 면역이 되며, 정화된 영역(받는 피해 30% 감소)이 생깁니다.

### 동료 지원 — 연하

| 패시브 | 효과 |
|---|---|
| 기억 소리의 울림 | 낙인 3중첩 이상인 적은 이동속도 감소, 3중첩 이상 개화 시 영로 회복 1.5배 |
| 생기 인화의 음률 | 체력 20% 이하일 때 자동 발동: 체력 회복, 백묵화 2단계로 차감, 3초 무적 (쿨타임 90초) |

## 진행 구성

1. **잡몹 웨이브** — 구해의 마물 2차 웨이브
   - **탁기 궤웅**: 돌진 후 자폭하고 탁기 웅덩이를 남깁니다 (밟으면 이동 감속, 회피 쿨타임 증가).
   - **묵식귀**: 원거리 탁기 구체를 쏘고, 탁기 안개 안의 적은 정화 피해를 50%만 받습니다. 먼저 처치하는 게 좋습니다.
2. **청류 등장 컷씬** — 설정집 보스전 Intro 대사
3. **보스전: 청류 · 청류의 수호신**
4. **정화 완료** — Outro 대사, 결과 화면(등급 S~C, 전투 통계)

### 청류 공략

| 페이즈 | 패턴 | 대응 |
|---|---|---|
| 1페이즈 | 수류 3연격 · 청류보(순간이동 베기) · 수파 일섬(직선파) | 붉은 예고 범위를 보고 회피, 검 모드라면 역린공명 |
| 1페이즈 | **유수 반격 자세** (푸른 기운) | 근접 공격하면 흘려보내고 반격합니다. 기다리면 빈틈(기절)이 생깁니다 |
| 2페이즈 (HP 70%) | 청룡의 도류 — 수룡의 소용돌이 | 끌려가는 힘을 버티며 범위 밖으로 달리거나 회피 |
| 룬 페이즈 (HP 50%) | 『청룡의 정화 룬(水)』 3개 · 받는 피해 80% 감소 · 방어막 재생 · 낙인이 씻겨나감 · 룬 물결이 방어막을 지움 | **파회법**: 붓 `묵향결쇄`로 룬 3개에 먹선 연결 → 검 `유묵섬참` 또는 `역린공명`으로 폭파 → 청류 긴 기절, 받는 피해 150% |

> 팁: 지면 공격과 룬 물결은 **점프로 넘을 수 있습니다** (투사체는 제외).

## 파일 구성

```
index.html   게임 전체 (HTML · CSS · JavaScript 단일 파일)
README.md    이 문서
```

`index.html` 내부 구성:

| 구역 | 내용 |
|---|---|
| 렌더러 · 텍스처 · 환경 | 수묵 지면, 산, 대나무, 청매나무, 먹 입자 |
| 이펙트 | 참격 궤적, 먹물·비취 입자, 정화 데칼(꽃밭), 충격파 |
| 캐릭터 모델 | 연우(붓/검), 청류(청룡 환영 포함), 구해 마물 |
| 플레이어 행동 | 콤보 정의(`DEF`, `AIR`, `STRONG`), 스킬, 전환, 점프·내려찍기, 궁극기 |
| 적 AI | 궤웅, 묵식귀, 청류 보스 패턴 · 페이즈 · 인화 룬 |
| 진행 · UI | 웨이브 진행, 대화, HUD, 결과 화면, 입력(키보드 · 마우스 · 터치) |

전투 수치(피해량, 쿨타임, 범위)는 `DEF`, `AIR`, `STRONG`, `CD` 상수와 각 스킬 함수에 모여 있어 쉽게 조정할 수 있습니다.
