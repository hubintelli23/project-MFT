# 블루잉크 : 천년청묵 — 전투 체험판

> 현재 게임 버전: **v1.2** · 파일별 버전은 아래 [파일 구성](#파일-구성)과 `js/version.js` 참고

세계관 프로젝트 **MFT 『블루잉크 : 천년청묵』**(구 제목: 인화순환록) 설정집을 바탕으로 만든 **3D 액션 JRPG 전투 체험판(버티컬 슬라이스)**입니다.
**연우 · 연하 · 매향** 세 명을 1·2·3 키로 교대하며 싸우는 전투와 보스 23명(5대 가문 5 · 마교 1 · 심원회 5 · 월계 1 · 백명신궁의 화염의 존재 8 · 구야 · 하야 · 백야)과의 보스전을 **스토리 모드** 또는 **보스 선택**으로 브라우저에서 플레이할 수 있습니다.

- 장르: 3D 액션 JRPG (쿼터뷰 고정 카메라)
- 플랫폼: 웹 브라우저 (PC · 모바일, 모바일은 가로 화면 권장)
- 엔진: Three.js r128 (CDN 로드) · 빌드 도구 없이 `index.html` + 분리된 파일들로 동작
- 아트 방향: 수묵화 톤 — 탁기(검붉음)를 정화하면 비취색과 꽃잎이 번지는 연출

---

## 실행 방법

1. 압축을 풀고 `index.html`을 브라우저로 열면 바로 실행됩니다. 별도 설치나 빌드가 필요 없습니다.
2. `css/` · `data/` · `js/` 폴더가 `index.html`과 **같은 위치**에 있어야 합니다.
3. 인터넷 연결이 필요합니다. Three.js와 글꼴을 CDN에서 불러옵니다.
4. 웹에 올리려면 폴더 구조 그대로 GitHub Pages 같은 정적 호스팅에 업로드하면 됩니다.

## 교대 시스템 (v0.6)

세 명 모두 직접 조작할 수 있고, 대기 중인 동료는 위기 때 자동으로 끼어듭니다.

| | 연우 | 연하 | 매향 |
|---|---|---|---|
| 키 | `1` | `2` | `3` |
| 역할 | 딜러 & 탱커 (붓·검 근접) | 버퍼 & 제어자 (피리 음파, 중거리) | 힐러 & 필드 정화자 (은침, 중거리) |
| 체력 | 100 | 80 | 90 |
| 기본 공격 | 붓 = 낙인 / 검 = 개화 | 음파탄 1~4타 — **낙인 부여**, 4타 둔화 | 은침 1~4타 — **낙인 개화**, 4타 전부 개화 |
| 강공격 | 응묵결쇄 / 점묵폭화 | 오드아이 응시 (원뿔 낙인 2 + 둔화) | 대지 침술 (주변 개화 + 매화 진 설치) |
| 점프 공격 | 비묵호선 / 비검무공 | 공명 낙음 | 낙화침 |
| 점프 강공격 | 비취묵파 / 백아강하참 | 월하 공명진 (착지 둔화 + 낙인) | 매화 낙지침 (착지 개화 + 매화 진) |
| 스킬 Q | 만묵소진 / 점묵개화 | 적안 · 경고의 음 (주변 적 기절) | 매화혈맥진 (파티 전원 체력 +15% · 둔화 · 매화 진) |
| 스킬 E | 묵향결쇄 / 유묵섬참 | 청안 · 균열 노출 (받는 피해 +30% · 룬 방어막 절반 파쇄) | 생기 착근 (전방 개화 + 매화 진) |
| 궁극기 R | 천지수묵 : 만화정계 | 쌍안연화 : 적청인과록 (끌어모아 속박 + 낙인 5 + 연우 검 첫 참격 확정 치명) | 만화정계 : 대지개화 (10초간 파티 치명타 100% · 개화 1.5배 · 장판 소멸) |
| 교대 진입 공격 | 묵선 강림 | 피리 소리 진입 (둔화 + 낙인) | 매화 낙화 (개화 + 회복) |

- **캐릭터별 체력 · 궁극기 게이지**가 따로 있습니다. 대기 중인 동료는 조작 캐릭터가 준 피해의 30%만큼 궁극기가 찹니다. 방어막은 파티 공용입니다.
- **교대 쿨타임 1초**, 교대 직후 0.4초 무적. 궁극기 사용 중에는 교대할 수 없습니다.
- **쓰러지면 자동 교대**: 조작 캐릭터 체력이 0이 되면 살아 있는 다음 동료로 자동 교대합니다. 세 명이 모두 쓰러지면 패배합니다.
- **붓/검 전환(`Tab`)과 백묵화는 연우 전용**입니다. 백묵화 체력 침식은 연우를 조작할 때만 진행되고, 매향이 살아 있으면 40% 줄어듭니다. 연하·매향이 개화시키면 연우 백묵화가 절반만 찹니다.
- **원거리 캐릭터의 이점**: 연하·매향의 투사체는 청류의 **유수 반격 자세에 반격당하지 않습니다**.

### 지원 개입 (대기 중일 때 자동)

| 동료 | 발동 | 효과 |
|---|---|---|
| 연하 | 조작 캐릭터 체력 20% 이하 (쿨타임 90초) | 생기 인화의 음률 — 체력 회복, 백묵화 2단계로 차감, 3초 무적 |
| 매향 | 조작 캐릭터가 경직될 때 (쿨타임 30초) | 매화혈맥진 — 경직 해제, 백스텝, 주변 적 둔화 |

### 동료 패시브 (파티에 있으면 항상)

| 패시브 | 효과 |
|---|---|
| 연하 · 기억 소리의 울림 | 낙인 3중첩 이상 적 이동속도 감소, 3중첩 이상 개화 시 영로 1.5배 |
| 매향 · 생기 착근 | 개화할 때 5초마다 그 자리에 작은 매화 진 생성 |
| 매향 · 매화 침술 | 백묵화 체력 침식 40% 감소 |
| 매화 진 | 위에 서 있으면 초당 체력 4 회복, 진 근처 탁기 웅덩이 정화 (최대 4개) |

## 핵심 전투 시스템

### 딜링 루프 — 만묵형상(萬墨形象)

```
붓 모드로 먹선 낙인 부여 (최대 5중첩)
   → 검 모드로 전환해 낙인을 베어 개화(폭발)
   → 방어막 · 체력 · 백묵화 게이지 · 전환 게이지 충전
```

### 붓 모드 (낙인 · 제어 · 방어)

| 구분 | 기술 | 효과 |
|---|---|---|
| 공격 1~4타 | 횡참 → 역횡참 → 원형 참격 → 광역 묵화 개화참 | 부채꼴 범위 낙인, 3타 끌어당김, 4타 360도 넉백 |
| 강공격 | 응묵결쇄 | 낙인 2중첩 + 속박 |
| 점프 공격 | 비묵호선 | 공중에서 낙인 부여 (점프 1회당 2번) |
| 점프 강공격 | 비취묵파 | 내려찍어 지면 먹물 파동 · 광역 낙인 + 방어막 |
| 스킬 1 (`Q`) | 만묵소진 | 소용돌이로 적을 끌어모음 + 방어막 |
| 스킬 2 (`E`) | 묵향결쇄 | 부채꼴 먹물 분사, 속박 + 낙인 · **인화 룬에 먹선 연결** |
| 패시브 | 비취묵령결 | 붓 모드일 때 방어막이 천천히 재생 |

### 검 모드 (딜링 · 정화)

| 구분 | 기술 | 효과 |
|---|---|---|
| 공격 1~4타 | 사선 참격 → 역참 → 종참 → 정화의 십자 참격 | 타격마다 낙인 개화, 4타는 남은 낙인 전부 개화 |
| 강공격 | 점묵폭화 | 낙인 전부 개화(1.5배) + 대량 방어막 |
| 점프 공격 | 비검무공 | 공중 2연속 베기, 적을 띄움 |
| 점프 강공격 | 백아강하참 | 내려찍기 강타, 낙인 개화 + 잡몹 다운 |
| 스킬 1 (`Q`) | 점묵개화 | 관통 찌르기, 낙인 즉시 개화 |
| 스킬 2 (`E`) | 유묵섬참 | 3연속 돌진 참격 · **연결된 룬 폭파** |
| 회피 반격 | 역린의 검무 : 녹각공명 | 적 공격이 닿기 직전 회피하면 반격 + 방어막 |

## 전투 시스템 (v0.9 — 전투 시스템 기획서 반영)

### 방어 · 회피

| 요소 | 방법 | 효과 |
|---|---|---|
| **가드** | `C` 누르고 있기 | 정면 공격 피해 80% 감소(강한 공격은 50%) · 이동 느려짐 · 가드파쇄 공격은 막지 못하고 가드가 깨짐(0.8초 경직) |
| **패링** | 맞기 직전(0.2초)에 가드 | 피해 0 · **슈아 반격** (캐릭터별 반격기) · 적 스태거 크게 감소 · 청명도 · 영로 · 지원 게이지 획득 |
| **스웨이** | 맞기 직전(0.22초)에 회피 | 피해 0 · 시간 잠깐 느려짐 · 1.5초 안에 공격하면 피해 1.6배 반격 |
| **강체** | 보스 큰 기술 중 (금빛 막) | 경직 · 넉백 없음, 스태거 감소 25% — **가드파쇄 공격으로 깰 수 있음** |
| **방어막** | 체력 위 별도 바 | 피해를 먼저 흡수 · 가드파쇄는 방어막에 2배 피해 |
| **무적** | 회피 · 교대 · 연하 생기 인화 등 | 즉사 공격도 버팀 |

공격 예고 색: **붉은색** = 일반 · **보라색 ⚠가드 불가**(가드파쇄 · 잡기) · **주황색 ⚠스웨이 불가**(가드 · 점프로 대응) · **검은색 ⚠즉사**(무적 · 범위 밖으로). 연하가 파티에 있으면 오드아이로 위험 공격을 미리 알려줍니다.

### 가드파쇄 · 스태거 · 무력화

- **가드파쇄 공격**: 각 캐릭터 강공격 · 점프 강공격 · 연우 검 4타 · 점묵개화. 적 가드 · 강체를 깨고 스태거를 3배로 깎습니다.
- 보스 HP 바 아래 **스태거 게이지**가 0이 되면 **무력화** 4.5초 (받는 피해 1.3배) → 게이지가 다시 찹니다. 잡몹도 무력화됩니다.

### 자원

| 자원 | 차는 방법 | 쓰는 곳 |
|---|---|---|
| **청명도** | 개화 · 패링 · 스웨이 · 처치 · 무력화 (맞으면 감소) | 가득(100) + 침식도 3단계 이상 → **영로화경** 진입 |
| **영로** | 공격 적중 · 강공격 · 개화 · 패링 · 처치 | Q/E 스킬 사용 (15~30) |
| **백묵화 침식도** | 개화 | 단계별 강화 (아래 표) |
| **녹기** | 영로화경 상태 | R → 녹기현경 (이동 · 공격 속도 1.3배) |

### 붓 ↔ 검 전환 · 연계

- 전환은 **자원 소모 없음 · 짧은 동작(0.18초) · 공격 없음**. 공격 중에도 타격 이후(캔슬 구간)라면 전환 가능, 경직 · 궁극기 중에는 불가.
- 전환 후 **1.3초 안에 공격**하면 연계기가 나갑니다 — 붓→검 `추사 정화`, 검→붓 `화묵이탈` (연계 게이지 FULL이면 `진명 정화` / `막묵 결계`).

### 동료 지원 게이지 · 공동 오의

연하 · 매향은 각각 지원 게이지(파티 칸 아래 금색 줄)가 있습니다. 적중 · 강공격(더 많이) · 패링 · 스웨이 · 무력화 · 개화 · 정화로 찹니다. 가득 차면 연우 조작 중 공동 오의를 쓸 수 있습니다.

| 키 | 공동 오의 | 효과 |
|---|---|---|
| `Z` (붓) | 연우&연하 『쌍안연화』 | 시간 정지 + 넓은 범위 낙인 5중첩 · 약점 노출 |
| `Z` (검) | 연우&연하 『녹기쌍룡 : 연하정화참』 | 결계 · 가드 · 강체 파괴 + 큰 피해 · 15초간 체력 침식 없음 |
| `X` | 연우&매향 『만화정계 : 대지개화』 | 대지 개화 광역 피해 + 파티 회복 · 방어막 |
| `V` | 삼인 『삼라만화 : 개화』 | **침식도 3단계 이상 + 두 게이지 가득** · 전투당 1회 · 3단 연출 · 15초간 보스 피해 증가 · 탁기 · 침식 면역 |

### 붓 ↔ 검 전환 연계기

| 방향 | 기본 전환 | 게이지 FULL 강화 전환 |
|---|---|---|
| 붓 → 검 | 추사 정화 (돌진 찌르기 + 개화) · 환묵잔영 분신을 남김 | 진명 정화 (화면 전체 개화 + 치명타 강화 + 체력 침식 일시 정지) |
| 검 → 붓 | 화묵이탈 (후방 점프 + 광역 낙인) · 비검 사출 | 막묵 결계 (주변 속박 + 낙인 5중첩 + 방어막 최대 + 붓 범위 확대) |

### 백묵화(白墨化)

개화할 때마다 게이지가 찹니다. 강해지는 만큼 위험도 커집니다.

| 단계 | 게이지 | 명칭 | 효과 |
|---|---|---|---|
| 1 | 25% | 용의 비늘 | 받는 피해 -10%, 경직 저항 |
| 2 | 50% | 용안 개안 | 치명타 +20% |
| 3 | 75% | 사지 야수화 | 이동·공격 속도 증가, 회피·대쉬 시 잔상 공격 |
| 4 | 침식도 75% 이상 + 청명도 100 | **영로화경** | 피해 +30%, 전신 순백화 · **청명도가 계속 줄어듦**(0이 되면 풀리고 침식도 하락) · `R`로 5단계 발동 가능 |
| 5 | 4단계에서 `R` | 녹기현경 : 멸화정계 | 백룡 낙하 광역 피해 + **이기어검 · 오룡정계** 15초 (허상의 검 4자루 자동 공격, 피해 1.5배, 체력 침식 없음, 청류의 정화 룬 즉시 파쇄) → 끝나면 1단계로 |

궁극기 **『천지수묵 : 만화정계』**(궁극기 게이지 100)를 쓰면 백묵화가 **1단계(25%)만 내려가고**, 10초간 탁기에 면역이 되며, 정화된 영역(받는 피해 30% 감소)이 생깁니다.

**5단계 『녹기현경 : 멸화정계』**는 백묵화 4단계(영로 화경)일 때 `R`로 발동하며 **궁극기 게이지가 필요 없습니다.** 4단계가 되면 궁극기 버튼이 「녹기현경」으로 바뀌고 빛납니다. 4단계에서 `R`은 천지수묵 대신 녹기현경이 우선 발동합니다.

### 겉모습 교체 · 추가하는 법 (js/assets/)

- **아바타**: `avatars.js`의 `AVATARS` 목록에서 해당 캐릭터의 만드는 함수를 고칩니다. 사람형 아바타는 오른팔 관절(`userData.piv`), 무기 쥐는 곳(`userData.hand`), 재질(`userData.robe` · `userData.hair`)이 있어야 공격 동작이 맞게 움직입니다.
- **무기**: `weapons.js`의 `WEAPONS` 목록에서 함수를 바꿉니다. 예: `yeonwooSword`를 바꾸면 연우의 검만 바뀝니다.
- **이펙트**: `effects.js`에 함수를 추가하고 `addFx(오브젝트, 수명, 매 프레임 갱신 함수)`로 등록합니다.
- **배경**: `background.js`만 고치면 하늘색 · 안개 · 지면 · 소품이 바뀝니다. 움직이는 배경은 `updateBackground(dt)` 안에 넣습니다.
- 나중에 `.glb` 3D 모델로 바꿀 때도 같은 이름의 함수가 3D 오브젝트를 돌려주게만 하면 나머지 게임 코드는 고칠 필요가 없습니다.

> 파일은 `index.html`에 적힌 순서대로 불러옵니다 (`version` → `data` → `js`). 순서를 바꾸면 동작하지 않을 수 있습니다.

### 버전 규칙

- 게임 버전(`GAME_VERSION`)은 업데이트할 때마다 올립니다. 타이틀 화면에 표시됩니다.
- **파일 버전은 그 파일이 마지막으로 바뀐 게임 버전**입니다. 예: v0.5에서 `boss.js`만 고치면 `boss.js`만 v0.5, 나머지 파일은 v0.4를 유지합니다.
- 파일을 고치면 세 곳을 같이 올립니다:
  1. 그 파일 첫 줄 주석의 버전
  2. `js/version.js`의 `FILE_VERSIONS`
  3. `index.html`의 해당 `<script src="...?v=">` (또는 `<link href="...?v=">`) 값 — 휴대폰 브라우저가 예전 파일을 캐시해서 쓰지 않게 해줍니다.
- 새 버전을 만들면 `updates.json`의 `updates` 맨 앞에 변경 내용과 추가/변경/삭제된 파일을 기록합니다.
- 일시정지 화면에서 현재 파일별 버전을 확인할 수 있습니다.
